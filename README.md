# Mimeo

Copies your chat windows and their settings (names, colours, sizes, positions, message types, channels) from one character to another, or as a string you can paste anywhere. For WoW Forever.

## Install

Copy the `Mimeo` folder into `World of Warcraft/_forever_/Interface/AddOns/`. Type `/mimeo` in game. A character shows up in the list once it has logged out with Mimeo on.

Inspired by Copybara by MickeyPickey. Copybara export strings import too.
